What it does

  • Group and search your work links
  • Open recent and featured links from the menu bar
  • Import configuration and back up your workspace

Before you start

Opens links in your default browser. HTTPS reachability checks run when requested. This is a link launcher, not a cloud sync or team collaboration service.

Use the Mac App Store listing for purchase, downloads, updates and current pricing.
