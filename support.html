KSIC Studio Support

KSIC Studio is a local-first macOS work launcher. If you run into any issues, the information below may help.

Contact Support

support@kevinlabs.app

Please include your macOS version, app version, reproduction steps, and screenshots (without personal data). We typically reply within three business days.

Frequently Asked Questions

Where is my data stored?

Work groups, entries, and Recents stay in the macOS App Sandbox and are never uploaded to remote servers.

Why does an HTTP address show no health status?

For connection security, the app only checks HTTPS addresses. HTTP addresses can still be opened in your default browser.

How do I migrate my configuration?

In Settings, import a JSON configuration file or use the backup and restore features. We recommend backing up before importing.

How does language selection work?

The app automatically follows the preferred language set in macOS System Settings. Change your preferred language in macOS Settings, then relaunch the app.

How do I remove all data?

Use "Restore Default Entries" in Settings. Please export any configuration you wish to keep before proceeding.

KSIC Studio 支持

KSIC Studio 是一款本地优先的 macOS 工作入口管理器。使用中遇到问题，可以先参考以下说明。

联系支持

support@kevinlabs.app

请附上 macOS 版本、App 版本、复现步骤和不含隐私信息的截图。通常会在 3 个工作日内回复。

常见问题

数据保存在哪里？

分组、入口和最近使用记录保存在 macOS App Sandbox 沙盒中，绝不会自动上传到远程服务器。

为什么 HTTP 地址没有健康状态？

为保护连接安全，App 仅检查 HTTPS 地址；HTTP 地址仍可正常交给系统默认浏览器打开。

如何迁移配置？

在“设置”中选择导入 JSON 配置文件，或使用导出与恢复功能。导入前建议先导出备份。

语言如何切换？

App 自动跟随 macOS 系统中为该 App 选定的首选语言。请在 macOS 系统设置中更改 App 语言后重启 App 即可。

如何删除全部数据？

在“设置”中使用“恢复默认入口”。执行该操作前请先导出需要保留的配置。

隐私政策

请阅读 KSIC Studio 隐私政策。

KSIC Studio サポート

KSIC Studioは、ローカルファーストのmacOSワークランチャーです。問題が発生した場合は、以下の情報をご確認ください。

サポートへのお問い合わせ

support@kevinlabs.app

macOSバージョン、アプリバージョン、再現手順、個人情報を含まないスクリーンショットを添えてご連絡ください。通常3営業日以内に返信いたします。

よくあるご質問

データはどこに保存されますか？

ワークグループ、エントリー、最近使用した履歴はすべてmacOSのApp Sandbox内に保持され、外部サーバーに自動アップロードされることはありません。

なぜHTTPアドレスには稼働状況が表示されないのですか？

接続のセキュリティ保護のため、HTTPSアドレスのみヘルスチェックを行います。HTTPアドレスも既定のブラウザで通常どおり開くことができます。

設定を移行するにはどうすればよいですか？

「設定」からJSON設定ファイルをインポートするか、バックアップ・復元機能をご利用ください。インポート前にバックアップをお勧めします。

言語の切り替え方法は？

macOSのシステム設定で指定された言語に自動的に従います。macOSの設定でアプリ言語を変更し、アプリを再起動してください。

すべてのデータを削除するには？

「設定」の「デフォルトエントリーを復元」を使用します。実行する前に保持したい設定をエクスポートしてください。

プライバシーポリシー

KSIC Studio プライバシーポリシーをご確認ください。

KSIC Studio 지원

KSIC Studio는 로컬 우선 macOS 워크 런처입니다. 문제가 발생한 경우 아래 정보를 참조하세요.

고객 지원 문의

support@kevinlabs.app

macOS 버전, 앱 버전, 재현 단계 및 개인 정보가 포함되지 않은 스크린샷을 첨부해 주세요. 보통 영업일 기준 3일 이내에 답변드립니다.

자주 묻는 질문

내 데이터는 어디에 저장되나요?

작업 그룹, 항목 및 최근 기록은 macOS App Sandbox에 안전하게 보관되며 원격 서버로 전송되지 않습니다.

HTTP 주소에 상태가 표시되지 않는 이유는 무엇인가요?

연결 보안을 위해 HTTPS 주소만 상태를 확인합니다. HTTP 주소도 기본 브라우저에서 정상적으로 열 수 있습니다.

구성을 마이그레이션하려면 어떻게 해야 하나요?

설정에서 JSON 구성 파일을 가져오거나 백업 및 복원 기능을 사용하세요. 가져오기 전에 미리 백업해 두는 것이 좋습니다.

언어 선택은 어떻게 작동하나요?

macOS 시스템 설정에 지정된 언어를 자동으로 따릅니다. macOS 설정에서 언어를 변경한 후 앱을 다시 실행하세요.

모든 데이터를 삭제하려면 어떻게 해야 하나요?

설정에서 '기본 항목 복원'을 사용하세요. 실행하기 전에 보관할 구성을 먼저 내보내세요.

KSIC Studio Support

KSIC Studio ist ein lokaler macOS-Work-Launcher. Bei Problemen helfen Ihnen die folgenden Informationen.

Support kontaktieren

support@kevinlabs.app

Bitte geben Sie macOS-Version, App-Version, Schritte zur Reproduktion sowie Screenshots (ohne private Daten) an. Wir antworten in der Regel innerhalb von 3 Werktagen.

Häufig gestellte Fragen

Wo werden meine Daten gespeichert?

Gruppen, Einträge und der Verlauf verbleiben in der macOS App Sandbox und werden niemals auf externe Server hochgeladen.

Warum haben HTTP-Adressen keinen Status?

Aus Sicherheitsgründen prüft die App nur HTTPS-Adressen. HTTP-Adressen werden weiterhin in Ihrem Standardbrowser geöffnet.

Wie migriere ich meine Konfiguration?

In den Einstellungen können Sie eine JSON-Datei importieren oder Backup & Wiederherstellung nutzen.

Wie funktioniert die Sprachauswahl?

Die App folgt der in den macOS-Systemeinstellungen gewählten Sprache. Nach der Sprachänderung die App neu starten.

Wie lösche ich alle Daten?

Nutzen Sie „Standardeinträge wiederherstellen“ in den Einstellungen. Exportieren Sie vorher gewünschte Konfigurationen.

Contacter l'assistance

Foire aux questions

Où sont stockées mes données ?

Vos groupes, entrées et récents restent dans le bac à sable (App Sandbox) de macOS et ne sont jamais téléversés.

Pourquoi une adresse HTTP n'a pas d'état de santé ?

Pour la sécurité, l'application ne vérifie que les adresses HTTPS. Les liens HTTP s'ouvrent toujours dans votre navigateur par défaut.

L'application suit la langue définie dans les Réglages Système de macOS. Modifiez la langue dans macOS puis relancez l'app.

Comment effacer toutes les données ?

Utilisez « Restaurer les entrées par défaut » dans les Réglages. Pensez à exporter vos données au préalable.
