Website privacy

Updated September 5, 2026. This notice covers this support website; each app has its own linked privacy policy.

Browsing and preferences

This site uses privacy-first, cookie-free web analytics (Cloudflare Web Analytics) to understand aggregated traffic and page performance without collecting personal data, tracking across sites, or setting cookies. It stores your chosen language in browser local storage. You can clear it through your browser’s site-data settings.

Hosting and external links

GitHub Pages hosts these pages and may process IP addresses and request metadata to deliver and secure them. See GitHub’s privacy statement. Following an App Store link takes you to Apple, whose policies govern purchases and downloads. We do not receive your payment-card information through this site.

Support email

If you email support, the recipient and email service process your address, message and any attachments to handle your request. Do not send passwords, payment information or private customer data. Send questions about your support correspondence or a deletion request to the address you contacted; applicable retention requirements may apply.

Website questions: support@kevinlabs.app.

网站隐私说明

更新于 2026 年 9 月 5 日。本说明适用于此支持网站，各应用的数据处理方式请查看其独立隐私政策。

浏览与偏好

本网站使用注重隐私、无 Cookie 的轻量网页分析（Cloudflare Web Analytics），仅用于统计汇总访问量与页面表现，不收集个人身份信息，不跨站跟踪，也不使用 Cookie。所选语言保存在浏览器本地存储中，可通过浏览器的网站数据设置清除。

托管与外部链接

本网站由 GitHub Pages 托管，托管方可能处理 IP 地址和请求元数据以提供页面及保障安全，详见 GitHub 隐私声明。点击 App Store 链接后将进入 Apple 服务，购买与下载适用其政策。本网站不会接收你的支付卡信息。

支持邮件

发送支持邮件时，收件人和邮件服务会处理你的邮箱地址、正文和附件，以处理请求。请勿发送密码、支付信息或客户隐私数据。如需查询或请求删除支持邮件，请联系原收件地址；适用的数据保留要求仍可能生效。

网站问题请联系 support@kevinlabs.app。

ウェブサイトのプライバシー

更新日: 2026年9月5日。本告知はこのサポートウェブサイトに適用されます。各アプリのプライバシーポリシーは個別にリンクされています。

閲覧と環境設定

当サイトでは、プライバシーを尊重したクッキー不要のウェブ解析（Cloudflare Web Analytics）を使用して、個人情報の収集やサイト間追跡、クッキーの設定を行うことなく、集計トラフィックとページパフォーマンスを把握しています。選択された言語設定はブラウザのローカルストレージに保存されます。

ホスティングと外部リンク

当サイトは GitHub Pages によりホストされており、配信およびセキュリティ保護のために IP アドレスやリクエストメタデータが処理される場合があります。詳細は GitHub プライバシーに関する声明 をご覧ください。App Store のリンクをクリックすると Apple のサービスに遷移し、購入やダウンロードには Apple のポリシーが適用されます。当サイトが支払いカード情報を取得することはありません。

サポートメール

サポート宛てにメールを送信された場合、お問い合わせに対応するため、受信者およびメールサービスがメールアドレス、本文、添付ファイルを処理します。パスワード、決済情報、または顧客の機密情報は送信しないでください。サポートとのやり取りに関するご質問や削除依頼は、お問い合わせいただいたメールアドレスまでご連絡ください（適用される法令に基づく保管義務が適用される場合があります）。

ウェブサイトに関するお問い合わせ: support@kevinlabs.app

웹사이트 개인정보 처리방침

업데이트: 2026년 9월 5일. 본 고지는 이 지원 웹사이트에 적용되며, 각 앱은 별도의 개인정보 처리방침 링크를 제공합니다.

브라우징 및 환경설정

이 웹사이트는 개인정보를 수집하거나 사이트 간 추적을 하지 않으며 쿠키를 설정하지 않고 집계된 트래픽과 성능을 파악하기 위해 쿠키 없는 웹 분석(Cloudflare Web Analytics)을 사용합니다. 선택한 언어 설정은 브라우저 로컬 저장소에 저장됩니다.

호스팅 및 외부 링크

이 웹사이트는 GitHub Pages를 통해 호스팅되며, 페이지 제공 및 보안을 위해 IP 주소와 요청 메타데이터가 처리될 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참조하십시오. App Store 링크를 클릭하면 Apple 서비스로 이동하며 구매 및 다운로드에는 Apple의 정책이 적용됩니다. 본 사이트는 결제 카드 정보를 일체 수집하지 않습니다.

지원 이메일

고객 지원팀에 이메일을 보내실 경우, 문의 처리를 위해 수신자 및 이메일 서비스에서 이메일 주소, 내용 및 첨부파일을 처리합니다. 비밀번호, 결제 정보 또는 기밀 데이터를 전송하지 마십시오. 지원 내역에 대한 문의나 데이터 삭제 요청은 문의하셨던 이메일 주소로 보내주시기 바랍니다 (법적 보관 의무가 적용될 수 있습니다).

웹사이트 관련 문의: support@kevinlabs.app
