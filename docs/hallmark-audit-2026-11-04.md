# Kevin Labs 全站 Hallmark 复审

日期：2026-11-04。基线：网站 2.0.0，Git `6a38c6c`。规则：Hallmark v2.0.0，audit 分支；保留已确认的 design.md 黑白灰与青绿品牌系统。

**结论：共享页面已形成一致的视觉系统，但不能宣称全站通过 Hallmark。仍有 4 项明确待改进问题，另有旧 CSS 的规则债务。** 本次审查未擅自重写隐私正文或把阅读页改为营销落地页。用户在复审期间明确要求的三项产品图调整已实施，网站版本更新为 2.0.1。

## 范围与证据

- 全部 29 个本地 HTML 页面：19 个共享主题页面、7 个跳转页、3 个视频页。路由明细见同目录 evidence JSON。
- 原始 `sloplint --genre modern-minimal --render --before --json` 扫描 31 个 HTML/CSS 文件，输出 145 张截图，包含 1280×800、1440×900、1920×1080 首屏及 1440/375 全页。
- 19 个共享页面 × 4 个宽度（320、375、1280、1920）× 8 种语言，共 608 组浏览器检查：没有可见元素越出横向视口，全部保持单一正文语言。
- 独立子代理按 Hallmark finish-review 流程复核首页、产品页、支持目录、指南、隐私与视频截图，结论 `fix`。确认重点为选择器对比度和视频主题缺口。
- 自动测试另行覆盖现有 SmoothCast 数据、语言偏好传播、旧跳转及新主题目录和素材引用。
- 禁用脚本检查，以及源 DOM 顺序和计算样式检查，补充视觉扫描。
- 本次为本地当前仓库审查，不是对所有外部产品网站及 App Store 的认证或可用性检查。

## 原始扫描结果与误报处理

原始结果为 **233 FAIL、84 REFLEX、110 WARN**；这是规则命中次数，**不等于 233 个独立用户可见缺陷**，也没有全部被撤销或修复。明确分类如下：

- 宽屏容器告警存在隐藏语言节点干扰。实测首页在 1920px 时正文左边为 344px，宽度 1232px，标题左边也是 344px，限宽居中有效；不能据“0px”告警改成全宽。
- `site.css` 的原始过渡、暗色样式与旧颜色字面量仍会被静态计数。最终视觉需要结合后加载的 monochrome.css 判断；源码 token 规则债务仍须记录。
- 离屏 `.skip` 是跳过导航入口；不能把它在未聚焦时的 -10000px 当作用户看到的横向溢出。
- 隐藏语言块的累计文案不能作为当前屏幕字数。日期、法律条款、长指南和支持资料也不按“一个营销首屏一句话”删减。
- 文档页小标题、紧凑间距和短页面不按营销页首屏高度硬修；这是 design.md 明确保留的阅读布局。
- 跳转页可能已呈现外部目标页面；截图不能重复计为本仓库独立页面，也没有据此宣称审过外站全部路径。
- 原生播放器在截图中的黑底不是品牌颜色缺陷；播放器焦点扫描值不能替代实际键盘验证。此项未扩大为确定缺陷。
- 旧标题标点、箭头和中点、旧页面 token 等机械问题仍保留在原始记录，不能声称“0 FAIL”。

原始 JSON、浏览器逐项证据及截图保留在本地 `.hallmark/audit-2026-11-04/` 及各路由的 `.hallmark/before/`，未把大量临时截图加入 Git。精简、脱敏且可审阅的证据汇总见 `hallmark-audit-2026-11-04-evidence.json`。

## 本次按用户要求完成的素材调整

1. **VolMix：首页和产品详情页**删除旧演示视频裁剪面板的引用，换成官方 App Store Connect 提交素材的同构中英文预览。来源为 VolMix 项目的 `AppStore/screenshots/shot1-v2/`，1440×900 文件已与其 manifest SHA-256 核对。中文页面用中文图，其余语言用英文图回退；没有改动应用版本或商店配置。
2. **BarNest Pro：首页展示图**换成用户本次明确提供的 1374×1031 新图，按比例完整显示；不覆盖旧版 BarNest 操作指南。移除展示块中重复且属于旧界面的图标，避免 Pro 与旧版品牌混用。
3. **PresenterDeck：首页和详情页**移除用户指出的深蓝旧演示海报，保留应用入口、原功能说明、视频页及视频本身。首页调整为 VolMix 图文展示及其余应用的紧凑文字目录，没有留下空白图框。

这些替换解决了本轮指定素材问题，不等于上面的全站待改进项已关闭。

## 2.0.2 修正进展（2026-11-04）

用户随后授权修正，并指出首页两块产品展示左栏空白。已完成：

- 选择框和次操作按钮边框改用 `--field-border:#767676`，白底边界对比超过 3:1；装饰分隔线不改。
- 19 个共享页头的品牌链接移到真实 DOM 首位，移除反向 CSS order，键盘顺序与视觉一致。
- HTML 默认只显示完整英文内容；脚本继续按用户偏好即时切换八种语言，无脚本隐藏不可用语言选择器。没有把正文变成必须依靠 JavaScript 才能出现。
- 三个视频页共用 assets/video.css，白底、近黑文字、中性灰内容区，保留原视频源、下载入口、analytics 和原生控件；焦点显式设置。
- 首页 BarNest Pro 和 VolMix 左栏增加八语的用途标题、简短说明和查看入口，调整图文比例，原始图片完整保留。
- 旧 assets/site.css 的颜色字面量集中到根 token，去除 transition:all 和 toast 的 100vw；跳转正文入口改为本地裁剪隐藏，避免靠负坐标放到视口外。

浏览器运行验证：19 个共享页面 × 4 个宽度 × 8 种语言，共608组合，单一可见语言、图片加载及无横向越界通过。原始链接和视频 source 完整性比对通过。节点级对比和键盘测试证据保留在 `.hallmark/fix-2.0.2/`。
