## 范围与验证

- 初始清单：五个实际域名的 86 个根页、内容页、历史兼容页、固定语言路径和动态购买页；每路由 8 个语言参数 × 390/1440px，共 1,376 次生产页面观察。均 HTTP 200，无可见元素横向越界和破图；发现 MindCharge 购买页脚本错误并修正。并未把不同参数误当作不同内容页面。
- 全清单均浏览器加载；其中 47 个非固定翻译／兼容转发代表路径制作截图总览，另对首页、工具网格、详情、四站页眉页脚原尺寸查看。不能由缩略图声称每个像素完美。
- 主站 19 项测试、154 个布局组合（320–1440px，断点两侧）及 16 组八语交互通过。四站既有回归：NextMirror 33、MindCharge 37、BarNest 56、SmoothCast 36；四站 320/390/768/1440px 共 16 个本地外观观察通过。
- 自动无障碍扫描使用 axe-core 4.11.0、WCAG2A/AA、2.1AA、2.2AA 标签，在每个路由的中文参数、390/1440px 两视口执行；初轮未返回违规。并非 WCAG 认证，44px 为项目设计目标；正文内链接及原生媒体控件另按语义判断。
- 检查 73 个站内内容目标；两个 /buy 的 HEAD 404 属于方法不支持，复核 GET 均 200，未误报为购买页面消失。付款、邮件、下载与第三方统计请求被阻断。
- 网站构建与安装包摘要、BarNest 历史包和更新签名复核通过，保留 Git 忽略的原发布资源；付款／授权／统计后端、App 制品、价格与许可证权益未修改。
